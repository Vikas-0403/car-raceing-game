# Console Car Racing Game

A simple **console-based Car Racing Game** written in C.

---

## 🎮 Game Features
- Move the car left and right using `A` and `D` keys
- Avoid multiple falling obstacles
- Score increases as you survive
- Game speed increases over time (dynamic difficulty)
- Start menu and Game Over screen with restart option

---

## 🛠️ Technologies Used
- C programming language
- Console-based ASCII graphics
- Windows-specific libraries (`conio.h`, `windows.h`)

---

## 🕹️ How to Play
1. Run the compiled executable (`CarGame.exe`)
2. Press `ENTER` to start
3. Use keys `A` (left) and `D` (right) to move
4. Avoid obstacles
5. Survive as long as possible to increase score
6. After Game Over:
   - Press `R` to restart
   - Press `ESC` to quit
